# Cardboard
Cardboard is a general-purpose modding library to simplify mod development, inspired by [Utilla](https://github.com/legoandmars/Utilla) and [HoneyLib](https://github.com/BzzzThe18th/HoneyLib).

Cardboard comes with a pretty cool featureset, including:
- **Modded Lobby Handling**: Cardboard can manage its own modded lobbies, but you can also install Utilla or GorillaLibrary to let Cardboard pass through its gamemodes.
- **Asset Loading**: Cardboard includes an asset loading class that will load resources for you.
- **Patching**: Cardboard can handle Harmony Patching to reduce the size of your assemblies.
- **Input Handling**: Cardboard can handle and parse input from the controllers.
- **Windows/Linux Support**: Cardboard provides simple interfaces for cross-platform compatability over Wine/Proton, so your Linux users get the same performance and features as your Windows users.

## Installation
Cardboard is avaliable via [MonkeForge](https://monkeforge.org/view/cardboard), or you can [download it here](https://github.com/sirkingbinx/Cardboard/releases/latest) and install it yourself.
